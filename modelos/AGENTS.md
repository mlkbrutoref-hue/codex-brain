# AGENTS.md — modelo para um projeto

Leia MEMORIA.md e ESTADO.md antes de iniciar. Considere também as preferências globais copiadas e revisadas para este projeto.

- Inspecione o código antes de editar.
- Preserve mudanças existentes.
- Faça alterações mínimas e testáveis.
- Nunca exponha credenciais em logs ou commits.
- Ao terminar, atualize MEMORIA.md com decisões duráveis e ESTADO.md com o andamento real.
- Informe se as mudanças ainda dependem de commit, pull request ou merge.
