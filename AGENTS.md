# Regras para este repositório

Este repositório é um catálogo versionado de instruções e modelos para projetos Codex. Não é uma memória automática compartilhada com outros repositórios.

Ao trabalhar aqui:
1. Consulte GLOBAL.md, PROJETOS.md e MEMORIA.md.
2. Mantenha apenas instruções e decisões gerais, não segredos.
3. Atualize os registros ao concluir uma tarefa, com data e referência ao commit quando aplicável.
4. Não afirme que outros projetos foram sincronizados sem verificar seus repositórios.
5. Para aplicar preferências globais em outro projeto, inclua as regras relevantes no AGENTS.md desse projeto, ou configure um mecanismo explícito de distribuição.
6. Nunca armazene tokens, senhas, chaves privadas ou credenciais.
