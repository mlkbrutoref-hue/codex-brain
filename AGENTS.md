# Regras para este repositório

Este repositório é um catálogo versionado de instruções, modelos e skills para projetos Codex. Não é uma memória automática compartilhada com outros repositórios.

Ao trabalhar aqui:
1. Consulte GLOBAL.md, PROJETOS.md e MEMORIA.md.
2. Para tarefas que correspondam a uma skill listada em [skills/README.md](skills/README.md), leia o arquivo SKILL.md correspondente e as referências necessárias antes de começar.
3. Adapte quaisquer orientações de ferramentas da skill às ferramentas realmente disponíveis; não assuma que um arquivo do catálogo foi automaticamente instalado como skill.
4. Mantenha apenas instruções e decisões gerais, não segredos.
5. Atualize os registros ao concluir uma tarefa, com data e referência ao commit quando aplicável.
6. Não afirme que outros projetos foram sincronizados sem verificar seus repositórios.
7. Para aplicar preferências globais em outro projeto, inclua as regras relevantes no AGENTS.md desse projeto ou configure um mecanismo explícito de distribuição.
8. Nunca armazene tokens, senhas, chaves privadas ou credenciais.
