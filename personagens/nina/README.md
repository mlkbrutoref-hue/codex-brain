# Nina — referências visuais

Esta pasta é destinada à imagem **original** de referência do rosto da personagem Nina.

## Arquivo esperado

- `rosto.png` — referência oficial de identidade facial (**ainda não enviado**).
- `corpo.png` — referência corporal aprovada, se houver no futuro.

A descrição textual e as orientações estão em [PERSONAGEM_NINA.md](../../PERSONAGEM_NINA.md).

## Como usar
1. Preserve a imagem original sem regeneração nem ajustes automáticos.
2. Ao trabalhar com Nina, forneça a imagem como referência visual real na ferramenta de geração.
3. Não confunda referência de identidade com imagem de pose, roupa ou cenário.
4. Não diga que a referência está disponível no GitHub até que o arquivo exista e tenha sido verificado.

## Privacidade
O repositório está público. Uma imagem enviada ficará acessível publicamente e poderá permanecer em versões históricas mesmo depois da mudança para privado.
