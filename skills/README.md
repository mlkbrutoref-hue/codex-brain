## Como usar no Codex

O armazenamento no repositório central **não instala nem ativa uma skill automaticamente** em sessões de outros projetos.

- Ao trabalhar neste repositório, peça ao Codex para ler a skill desejada em `skills/<nome>/SKILL.md` e suas referências.
- Para descoberta automática como skill em outra instalação do Codex, use o procedimento de instalação de skills suportado por esse ambiente e mantenha a cópia sincronizada com este repositório.
- Não presuma que ferramentas específicas citadas por uma skill estejam disponíveis no ambiente atual.

Nunca adicione credenciais ou dados confidenciais ao catálogo público.
